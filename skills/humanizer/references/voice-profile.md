# Voice profile template

Copy this file into the project or working folder as `voice-profile.md` and fill it in.
The skill uses it when it exists. Skill files inside an installed plugin are read-only,
so don't edit this copy.

Samples matter more than descriptions. Three real messages say more about how someone
writes than any list of adjectives.
